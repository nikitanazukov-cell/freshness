## Измерения исключительно для технического теста

CPU, batch=1, PyTorch threads=2, искусственные изображения 176×128:

- Среднее полное время pipeline: 8.82 мс.
- P95 pipeline: 11.63 мс.
- Размер тестового FP32-checkpoint: 6,206,039 байт.
- Это **не** замер реальных фотографий пользователя и **не** обещание скорости на другом компьютере.
- Accuracy на этих искусственных данных не используется для подтверждения задания.

## Что не проверено и не заявляется

**Реальное качество трёхклассового распознавания не измерено.** Пользователь не предоставил размеченный датасет. В поставке нет модели, дообученной на настоящих продуктах; утверждения о достигнутой accuracy ≥ 75% нет.

**Режим Albumentations не выполнен в среде проверки.** Пакет отсутствовал, его установка оказалась недоступна из-за сетевых ограничений среды. Реализован режим Albumentations 2.0.8 с параметрами из документации; в тестах использован явный режим torchvision. В наборе тестов есть дополнительная проверка Albumentations, которая выполнится при установленном пакете.

**Скачивание официальных весов ImageNet здесь не выполнялось.** Код использует стандартный интерфейс torchvision с проверкой хеша при скачивании. Отдельно проверена ветка загрузки локальной инициализации и замены последнего слоя.

**Windows, GPU/CUDA и конкретный компьютер пользователя не тестировались.** Оконный интерфейс проверен в графической сессии Linux/Xvfb. Windows-скрипты и инструкция подготовлены, но не выданы за фактически выполненную установку Windows.

## Как воспроизвести

Из папки проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe main.py self-test --output outputs/self_test_new
.\.venv\Scripts\python.exe main.py self-test --augmentations albumentations --output outputs/self_test_albumentations
```

Подробный лог unit-тестов приложен в `docs/validation/unit_tests.txt`; сводка сквозной проверки — в `docs/validation/self_test_result.json`. Тестовый checkpoint и искусственные картинки не включены в архив, чтобы их не спутали с результатом НИР. Команда `self-test` воссоздаёт их локально.
